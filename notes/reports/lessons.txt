 IAM User: A specific person or automated service that holds credentials to interact with AWS.
 IAM Role: A temporary identity that a user or service can assume to gain permissions without requiring credentials.  
 Policy: A JSON document attached to a user or role that strictly defines which exact AWS actions they are allowed or denied to perform.
 Least Privilege: The core cloud security principle of granting an entity only the absolute minimum permissions required to execute its specific task.   
Never Commit Credentials to Git: If credentials leak into Git, automated bots scraping public repositories can get access to the account
